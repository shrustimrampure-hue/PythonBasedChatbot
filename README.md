# AI Chatbot using Gemini API

## Project Overview

This project is a simple AI chatbot developed using Python and the Google Gemini API. It allows users to interact with an AI model and receive responses in real time.

## 🎯 Objectives

- To understand Generative AI
- To build a simple AI chatbot
- To integrate the Gemini API with Python
- To provide real-time AI responses

## ⚙️ Technologies Used

- Python
- Google Gemini API

## 🛠 How It Works

- User enters a message
- The message is sent to the Gemini API
- Gemini processes the input
- The chatbot displays the generated response

## 🚀 Features

- Real-time AI conversation
- Gemini API integration
- Simple command-line interface
- Interactive user input
- Easy to use

## ▶️ How to Run

Install the required package:
```bash
pip install google-generativeai

Add your Gemini API key to the Python file and run:
python chatbot.py
